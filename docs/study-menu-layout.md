# 학습 메뉴 카드형 정리

학습 화면을 내 바로가기 → 전체 학습 → 추가 자료 순서로 정리했다. 학습 화면만 바꾸며 메뉴 id, 학습 데이터, 오답 기록, 일일 학습 흐름은 기존 연결을 사용한다.

- **내 바로가기:** 저장된 즐겨찾기를 고른 순서대로 표시한다. 기존 최대 6개를 유지하고 PC는 3열, 휴대폰은 2열이다. 비어 있으면 편집 안내를 보여 주며 임의의 즐겨찾기를 저장하지 않는다.
- **편집:** 칸을 눌러 추가·삭제하고 좌우 화살표로 순서를 바꾼다. 각 칸의 순서 번호를 표시하고, 스크롤해도 편집 상태·선택 수·완료 버튼은 위에 고정한다. 설정에서 숨긴 메뉴의 즐겨찾기 정보는 보존한다. 편집 중에는 추가 자료도 열려 있어 그 안의 메뉴를 선택할 수 있다.
- **전체 학습:** 켜진 N3 코스·JLPT 기출 단어·단어 암기·문법·한자·회화 문장·듣기를 고정된 순서로 보여 준다. 즐겨찾기에 넣어도 이 목록에서는 사라지지 않는다. 카드에는 왼쪽 아이콘, 이름, 짧은 설명을 표시한다. 퀴즈·오답 복습은 복습&내기록에 있다는 문구로 안내한다.
- **추가 자료:** 여행 일본어·영상·완전기초·독일어는 처음에 접혀 있으며 요약을 눌러 연다. 히라가나를 아직 못 읽는 사용자의 완전기초 안내는 맨 위에 유지한다.

스타일은 `src/styles/study-hub.css`에서 `.study-hub` 안에만 적용한다. 다른 작업자의 오류 수정 파일과 공용 학습 로직을 변경하지 않는다.

메뉴 이름 변경은 학습 화면의 표시 별칭이다. 기존 `n3`, `kiju`, `words`, `sentences` id와 저장된 즐겨찾기·학습 기록·메뉴별 화면 연결은 유지한다.

확인 범위: 메뉴 진입, 자료 접기·펼치기, 즐겨찾기 추가·삭제·6개 제한·순서 저장, 320/390/1050px 화면, 새로고침 후 순서 유지, 완전기초 진입. 전체 검사는 기존 CI에서 진행한다.
