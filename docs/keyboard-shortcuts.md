# 학습 단축키

학습 화면과 설정의 「키보드 안내」에서 같은 조작을 확인할 수 있다.

| 화면 | 키 | 동작 |
| --- | --- | --- |
| 선택형 퀴즈 | 1–9 | 화면의 보기 번호로 답 선택. 답한 뒤에는 해당 보기의 일본어 듣기(실전 시험의 해설은 시험 종료 뒤) |
| 퀴즈·쓰기 | Enter | 제출, 채점 뒤 다음 문제, 마지막 문제에서 결과 보기 |
| 카드 학습 | Enter | 답 보기, 답을 연 뒤 알아요로 진행 |
| 카드 학습 | 1 / 2 / 3 | 몰라요 / 애매해요 / 알아요. 답을 열기 전에는 먼저 뒤집기 |
| 카드 학습 | Space / Shift+Space | 듣기 / 천천히 듣기 |
| 카드 학습 | ← | 직전 판정 되돌리기 |
| 문장 조립 | 1–9 / ← | 남은 조각의 화면 순서대로 선택 / 마지막 조각 취소 |
| 문장 조립 | Enter / Space | 완성 뒤 다음 문장 / 완성 문장 듣기 |
| 연속 듣기 | Space | 일시정지·재개 |
| 연속 듣기 | ← / → 또는 Enter | 이전 / 다음 카드 |
| 연속 듣기 | ↓ | 현재 카드를 처음부터 다시 듣기 |
| N3 청해 | Space / ↓ | 재생·멈춤 / 대화 처음부터 다시 듣기 |
| N3 청해 | Enter / ← → | 들은 뒤 다음 단계 / 열린 단계 사이 이동 |
| 짝 맞추기 | 1–5 → 1–5 | 왼쪽 선택 뒤 오른쪽 짝 선택. ←로 선택 취소 |
| 공통 | Esc | 현재 학습 나가기. 설명창이 열렸으면 설명창부터 닫기 |

## 진행 방식

- 숫자키·Enter로 퀴즈를 풀기 시작하면 그 판에서는 자동으로 다음 문제로 넘기지 않는다. 해설을 읽은 뒤 Enter로 진행한다.
- 마우스·터치로만 푸는 기존의 정답 자동 진행과 보기 상세를 펼쳤을 때 멈추는 동작은 유지한다.
- 쭉 퀴즈의 10·20·30문제 묶음과 계속하기/종료, 오답 기억·재시험은 그대로 유지한다.
- 단어 시험과 쭉 퀴즈의 기존 5번 다음 키는 호환을 위해 남기되, 화면 안내는 Enter로 통일한다.
- 카드의 4번 뒤집기, 0번 장기 복습, Backspace 되돌리기는 기존 사용자 호환용이다. Z·X·C와 카드 보조 기능의 문자키는 제거했다. 보조 기능 버튼은 Tab으로 이동해 Enter로 실행할 수 있다.

## 입력·음성·확장 프로그램

- 글을 쓰는 동안 숫자와 Space는 입력에 사용한다. 조합 중인 일본어·한국어의 Enter는 제출하지 않는다. 채점으로 입력칸이 비활성화된 뒤에는 Enter로 다음 문제에 갈 수 있다.
- 길게 누른 키의 반복과 뒤쪽 화면의 중복 반응을 막는다. Tab으로 선택한 버튼·링크·안내 펼치기는 기본 키보드 조작을 유지한다.
- 읽기·표기·문장 조립 문제에서 답이 드러나는 음성은 답하기 전에는 재생하지 않는다. 단축키는 기존 음성 재생 함수를 사용하며 별도 API 키를 요구하지 않는다.
- Vimium 같은 확장 프로그램이 키를 먼저 처리하면 웹앱이 받을 수 없다. Vimium의 제외 URL에 `https://scott910512-source.github.io/japan/*`를 추가하고 Keys를 비워 사이트에서 비활성화한다. 로컬 미리보기는 해당 로컬 주소도 따로 제외한다.

## 확인

`test/ui/keyboard-flow.js`는 실제 화면에서 카드, 문법 시트, 쭉 퀴즈, 문장 조립·쓰기, 입력 조합, 연속 듣기, N3 시험·청해와 중첩 화면의 키 처리를 확인한다. 전체 검사는 기존 CI에서 수행한다.

## 잘못 눌린 입력

- 같은 키를 0.2초 안에 또 누른 것은 한 번으로 본다. 「답 보기」(Enter) 바로 뒤에 Enter가 한 번 더 들어가 「알아요」로 기록되는 일을 막는다. 다른 키는 바로 받는다.
- 같은 키를 일부러 빠르게 이어 누르는 화면(문장 조립 · 짝 맞추기)은 이 틈을 두지 않는다(`useHotkeys`의 `rapid`).
- 자동 조작(화면 검사)에서는 이 틈을 끈다(`navigator.webdriver`). 검사는 사람보다 훨씬 빨리 같은 자리를 이어 눌러서, 틈을 두면 돌릴 때마다 다른 검사가 멈췄다. 이 기능은 `test/ui/double-input-ui.js`가 `jp_input_guard = 'on'`으로 켜고 본다.
- 클릭도 같다. 같은 자리(24px 안)를 0.2초 안에 또 누른 것은 버린다(`lib/tapguard.js`). 글자를 치는 칸은 건드리지 않는다.
