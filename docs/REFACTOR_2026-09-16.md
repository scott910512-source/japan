# 정보구조 개편 — 탭 다섯에서 넷으로 (2026-09-16)

목적은 기능 추가가 아니라 **복잡해진 메뉴와 학습 동선을 단순하게** 만드는 것이다.
켜면 「어디 들어가서 공부하지」를 고민하지 않아야 한다.

    앱 실행 → 오늘 학습 시작 → 공부 → 복습 → 완료

학습 데이터·진도·복습 기록·SRS·설정은 한 칸도 지우지 않았고 저장 열쇠도 그대로다.
기능을 없앤 것이 아니라 **자리를 옮기고 중복 길을 하나로** 했다.

## 1. 개편 전 — 무엇이 어디 있었나

탭 다섯: 오늘 · 학습 · 듣기 · 기록 · 더보기. 밀어 넣는 화면(sub) 열여섯.

| 자리 | 있던 것 |
|---|---|
| 오늘 | 진행 카드(몇/몇·몇 분), 큰 버튼(이어하기/오늘 학습 시작/새로 배우기), 배정 내역(복습·새로 배우기), 곁들여서(오늘의 N3·오늘의 문법), 완료 카드, 「복습이 더 남았어요」→ 복습 화면 |
| 학습 | 배우기(한 권으로 끝내는 N3·단어·문법·상황회화·완전기초·독일어) / 연습하기(단어 시험·동사 활용·부사·짝·실전) / 반복하기(회독 학습·약점 복습) |
| 듣기 | 자동 듣기 · 따라 말하기 · 영상으로 배우기 |
| 기록 | 연속일, 오늘 배정/완료, 최근 7일 활동, 달력, 전체, 기억 수준, 「복습으로 가기」→ 복습 화면 |
| 더보기 | 설정 여섯 묶음(학습 설정·음성·계정과 동기화·기록 백업·학습 도구(내 단어장·번역기·독일어)·앱 정보) |
| 복습 화면(sub) | 복습 시작(복습일 된 단어), 문장 복습, 취약 단어, 기록 두 줄, 회독 현황 막대 |

### 같은 곳으로 가는 길이 여럿이었다

- 복습: 오늘의 「복습」 줄 · 오늘의 「복습이 더 남았어요」 · 기록의 「복습으로 가기」 · 학습의 「약점 복습」 · 복습 화면의 「취약 단어」 — 다섯 길, 화면 셋
- 통계: 복습 화면의 「기록」 두 줄과 기록 탭이 같은 숫자를 따로 그렸다
- 독일어: 학습 탭과 더보기 도구 둘 다
- 복습 배지: 탭바는 회독 저장소의 「복습일이 된 것」을 세고, 오늘 화면은 계획(plan)의 복습 갈래를 세서 숫자가 달랐다

## 2. 분류 — 유지 · 통합 · 이동 · 제거 후보

| 분류 | 항목 |
|---|---|
| 유지 | 오늘의 계획·큐(plan.js), 회독(Study), N3 코스, 단어·문법·문장·기초·독일어, 연습 다섯, 듣기·영상, 기록 내용, 설정 여섯 묶음, 온보딩, PWA, 동기화 |
| 통합 | 복습으로 가는 다섯 길 → **복습 탭 하나**. 복습 화면(ReviewTab)의 기록·현황은 내 학습에 이미 있어 삭제, 「복습 시작·문장·취약 단어」는 복습 탭으로 |
| 이동 | 듣기 탭 → 학습 탭 「듣기」 칸(자동·따라·영상). 더보기 → 내 학습의 「설정」 줄. 기록 → 내 학습. 회독 학습·약점 복습 → 복습 탭. 한 권으로 끝내는 N3 → 학습 탭 JLPT N3(첫 칸, 하나만 크게) + 홈 「이어서 공부하기」 |
| 제거 후보 | 오늘의 진행 카드(큰 버튼이 「약 N분 · N개」를 이미 말한다), 오늘 줄마다 붙던 「약 N분」, 복습 화면의 중복 통계. **데이터는 아무것도 안 지웠다** |

## 3. 새 정보구조

    홈        오늘 학습 시작(이어하기) · 이어서 공부하기(N3 코스 · 오늘 복습) · 오늘 목록 · JLPT N3 준비도 한 줄
    학습      JLPT N3 / 콘텐츠(단어 · 문법 · 한자 · 문장 · 듣기 · 영상) / 연습 / 그 밖에
    복습      오늘 복습 [복습 시작] · 틀린 문제 · 취약 단어 · 취약 문법 · 문장 복습 · 전체 복습
    내 학습   JLPT N3 진도·준비도 · 오늘 · 활동 · 달력 · 기억 수준 · 취약 영역 · 설정

- 홈의 정보 차례: ① 오늘 학습 시작 ② 오늘 복습 ③ 이어서(N3) ④ 오늘 진행 ⑤ N3 진도. 나머지 통계는 내 학습.
- 학습 탭에는 콘텐츠 종류만 있다. 「새로 배우기」 같은 행동은 홈이, 「복습」은 복습 탭이 한다.
- 한자 칸은 N3 코스의 한자 과정(50과 500자)을 그대로 연다 — 자료를 두 벌 두지 않는다.
- 클릭 수: 켜기 → 오늘 학습 시작 **1번**. 특정 공부: 학습 → 칸 **2번**. 설정: 내 학습 → 설정 → 묶음 **3번**(옛 더보기 → 묶음 2번보다 하나 늘었다 — 설정은 매일 여는 자리가 아니라 받아들였다).
- 학습(회독) 중에는 탭바를 두지 않는다. 나가는 길은 위쪽 닫기와 브라우저 뒤로가기.

## 4. 숫자는 한 곳에서

- 홈 「복습 N개」· 복습 탭 「오늘 복습 N개」· 탭 배지가 전부 `planStatus(plan)`의 복습·약점 갈래에서 나온다. 「복습 시작」은 바로 그 갈래로 큐를 짠다(`startToday(['review','weak'])`). 계획에 다 못 담은 것은 「밀린 복습 N개」로 따로 적고 `startDueDeck`으로 연다.
- 새로 배우기 수도 같은 계획에서 나온다 — 「2개 남음」인데 들어가면 비어 있는 일이 없다.
- 취약 단어 수는 복습 탭과 내 학습이 같은 `weakCards`를 본다.
- JLPT N3 진도·준비도는 코스가 열릴 때 실제 진도(`progressOf`)·준비도(`readinessOf`, 실제로 맞힌 결과)로 적어 두는 요약 `progress.n3.summary`에서 홈·학습·내 학습이 읽는다. 코스 자료(문법 123꼭지·한자 500자…)를 메인 번들에 싣지 않기 위해서다. 열어 봤다고 오르지 않는다.

## 5. 저장·경로 영향

- localStorage 열쇠는 하나도 안 바뀌었다. 옮긴 것은 화면이지 데이터가 아니라 migration이 필요 없다.
- `settings.menus`에 `kanji·listen·videos`가 늘었고 `repeat·weak`는 빠졌다. `loadSettings`가 기본값 위에 저장값을 얹으니 옛 사용자에게도 새 칸이 켜져 나오고, 남아 있는 옛 열쇠는 무시된다(`groupedMenus`는 `MENUS`에 있는 것만 그린다).
- `progress.n3.summary`가 새로 생겼다. `normalizeN3`가 없으면 `null`로 채우고, 기기 합치기(`mergeN3`)는 나중에 적은 쪽을 쓴다.
- 이 앱은 URL 경로(라우터)를 쓰지 않는다 — 탭과 밀어 넣는 화면은 상태이고, 뒤로가기는 `history.state`의 자리 하나로 처리한다. 그래서 깨질 북마크 경로가 없고 redirect가 필요 없다. 앱 주소(`/japan/`) 하나뿐이다.

## 6. 검증

- 화면 검사(진짜 크롬 390px): 홈 → 오늘 학습 시작 → 판정 → 회독 기록 반영 → 나갔다 와서 이어하기 → 내 학습 진도, 복습 탭에서 전체 복습(회독 학습), N3 코스 → 학습 → 종료 → 다시 접속 → 이어서, 네 탭 가로 넘침 없음, 옛 기록(oldstate)으로도 켜짐.
- 논리 검사: 메뉴 목록과 설정 열쇠가 서로 맞음(유령 칸 없음), N3 요약 합치기.
