# 검사

```bash
npm test          # 전부 (2~3분)
npm run test:logic  # 순수 함수만 (몇 초, 브라우저 필요 없음)
npm run test:ui     # 화면만
```

`npm test`는 `dist/`가 없으면 알아서 빌드하고, `vite preview`로 띄운 뒤 진짜 크롬으로
눌러 본다. **개발 서버가 아니라 배포될 결과물 그대로**를 본다 — 경로도 배포와 같은
`/japan/`이다.

크롬 경로가 다르면:

```bash
CHROMIUM=/path/to/chrome npm test
```

## 두 갈래

**`logic/`** — 순수 함수. 브라우저가 필요 없다.

| | 무엇을 지키나 |
|---|---|
| `logic.mjs` | 회독 규칙 전반 — 판정·간격·졸업·세션·취약 단어 |
| `goal.mjs` | 설정한 학습량과 실제 세션 장수가 같은가 |
| `twosync.mjs` | 아이폰·아이패드를 합칠 때 한 장도 안 잃는가, 순서를 바꿔도 같은가 |
| `syncwire.mjs` | 서버로 뭘 보내는가 (음성 키가 안 실리는지 포함) |
| `mergevid.mjs` | 뺀 영상이 다음 동기화에 되살아나지 않는가 |
| `clip.mjs` `script-test.mjs` | 자막 파싱·자르기 |
| `reason.mjs` | Gemini가 실패했을 때 이유를 제대로 옮기는가 |
| `audit-data.mjs` | 단어 2,330개 — 뜻·품사·읽기 충돌, 빈 칸, 읽기에 한자 섞임 |

**`ui/`** — 빌드한 앱을 크롬으로 조작한다.

| | 무엇을 지키나 |
|---|---|
| `fresh.js` | **처음 켠 사람** — 로그인 화면 → 안내 → 홈 → 첫 회독까지 |
| `qa-final.js` | 홈 메뉴를 하나씩 다 열어 본다 (흰 화면으로 죽는 것 잡기) |
| `ux.js` | 나갔다 와도 진도가 이어지는가, 되돌리기 |
| `study-flow.js` `judge-speak.js` | 회독 판정과 기록, 판정 음성 |
| `quiz-flow.js` | 시험 — 맞으면 넘어가고 틀리면 보기에서 설명 |
| `guard.js` | 회독 중 탭바, 영상 삭제 확인(「삭제」 입력) |
| `design.js` | **375px 두 테마** — 가로 넘침, 탭 크기(<32px), 명암비 |
| `video-ui.js` `lesson.js` `script-lesson.js` | 영상 목록·설명 학습·자막 학습 |
| `grab.js` `grabtoggle.js` | 자막 구하는 길, 직접 받아오기 스위치 |
| `vidsync.js` | 영상 상태가 기기에 남는가, 뺀 영상이 안 돌아오는가 |
| `gemini.js` `keyguard.js` | Gemini 호출 모양·실패 안내, 키 잘못 넣는 것 막기 |
| `jlpt-ui.js` | JLPT 레벨·세트 숫자 |

## 검사를 새로 쓸 때

형식만 맞추면 러너가 알아서 집어 간다.

- 파일을 `logic/`(`.mjs`)이나 `ui/`(`.js`)에 넣는다
- 마지막에 `` console.log(`\n통과 ${pass} / 실패 ${fail}`) `` 를 찍고 실패면 `exit(1)`
- `ui/`에서는 주소를 `BASE`, 크롬을 `CHROME`으로 받는다 (러너가 환경변수로 준다)

## 못 보는 것

여기서 못 잡는 게 있다. 이건 사람이 폰에서 봐야 한다.

- **소리** — 단어 읽어주기, 마이크 발음 확인
- **진짜 동기화** — 기기 두 대로 실제로 주고받는 것 (합치는 규칙은 `twosync.mjs`가 본다)
- **진짜 API** — Gemini 호출은 전부 가짜 응답으로 돌린다
- **사파리** — 크롬으로만 본다. 홈 화면에 추가한 앱의 갱신도
