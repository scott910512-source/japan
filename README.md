# 처음 가는 일본 🇯🇵

한국인 여행객이 일본을 여행하며 **일본어로 직접 말해야만 진행되는** 2D 씬 기반 어드벤처 학습 게임(PWA)입니다.

- 플레이어는 항상 **여행객/손님** — NPC(역무원·점원·호텔 직원·택시 기사…)와 일본어로 대화해 여행 상황을 해결합니다
- 틀려도 게임은 멈추지 않습니다. 의미가 통하면 대화가 이어지고, 교정은 여행 몰입을 깨지 않게 카드로 살짝 표시됩니다
- NPC 대화는 **Claude API로 실시간 생성**(AI 모드)되며, API 키가 없어도 **스크립트 모드**로 전체 퀘스트를 플레이할 수 있습니다

## 배포 (GitHub Pages)

빌드 도구가 필요 없습니다. 저장소 Settings → Pages → 브랜치 선택만 하면 바로 동작합니다.

## 사용법

1. 모바일 크롬에서 접속 → 설치 배너로 홈 화면에 추가 (오프라인에서도 실행됩니다)
2. (선택) 설정에서 Claude API 키 입력 → AI 모드 활성화
   - 키는 브라우저 localStorage에만 저장되며 코드·저장소에 포함되지 않습니다
3. 지도에서 챕터를 골라 여행 시작 — 챕터 1(공항)부터 순서대로 잠금 해제

## 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 셸 + 화면 템플릿 (타이틀/지도/씬/결과/숙소/도감/설정) |
| `style.css` | 파스텔 여행 포스터 무드 UI |
| `app.js` | 게임 상태·라우팅·씬 엔진·음성(TTS/STT)·저장·복습·적응형 루프 |
| `npc-engine.js` | Claude API 호출, 시스템 프롬프트 조립, JSON 파싱, 폴백 |
| `data.js` | 챕터 8개·퀘스트·표현·한자 카드·스크립트 분기 데이터 |
| `sw.js` | 서비스 워커 — 앱 셸 cache-first, Claude API network-only |
| `manifest.json` | PWA 매니페스트 (아이콘은 SVG data URI로 내장) |

## 주요 기능

- **챕터 8개**: 공항 도착 → 전철·길 찾기 → 호텔 체크인 → 식당 찾아가기 → 식당 주문 → 편의점·쇼핑 → 관광지 스몰토크 → 문제 해결
- **난이도 4레벨**: L1(문장 조합·상시 자막) ~ L4(실전 속도·힌트 없음)
- **음성**: NPC 대사 TTS(ja-JP, ゆっくり 재생), 마이크 음성 인식 입력(지원 브라우저)
- **교정 시스템**: major는 대화 중 카드, minor는 장면 종료 후 일괄 — 전부 오답 노트에 자동 저장
- **적응형 루프**: 약점 문법 태그 누적 → 다음 대화에 반영, 어제 오답이 오늘 퀘스트의 다른 상황에서 재등장
- **숙소(복습)**: 오늘의 상황·표현·내 문장 vs 교정문·한자 카드·다시 말하기 재도전·내일 예고
- **기억하는 NPC**: 스몰토크에서 말한 취미·일정 등을 다른 NPC가 기억하고 언급
