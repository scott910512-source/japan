API 키가 없으면 스크립트 모드로 플레이됩니다.

키를 넣으면 구글 최신 신경망 음성으로 훨씬 자연스럽게 말합니다. 비우면 기기 내장 음성 사용. 키는 이 브라우저에만 저장됩니다.

"역할 따라 자동"이면 심사관·역무원·택시기사·경찰은 남성 목소리, 나머지는 선택한 목소리로 말합니다.

📱 아이폰 발음 개선: 아이폰 설정 → 손쉬운 사용 → 콘텐츠 말하기 → 음성 → 일본어에서 「Kyoko (고급)」 음성을 다운로드하면 게임이 자동으로 그 목소리를 사용해 훨씬 자연스러워집니다. 안드로이드는 Google TTS의 일본어 음성을 설치하세요.
